# Wi-Fi Airtime Simulator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Browser SPA that simulates IEEE 802.11 DCF channel access at µs resolution inside a user-built 3D house, with a record-and-scrub timeline (pause, inspect, step forward/backward).

**Architecture:** Pure-TS deterministic discrete-event engine (Web Worker) emits an append-only timeline of records + periodic ViewState snapshots; the main thread is a player that scrubs/reconstructs state. Three.js viewport + React panels + 2D floor-plan editor.

**Tech Stack:** Vite, TypeScript (strict), React 18, Three.js, zustand, zod, vitest.

**Spec:** `docs/superpowers/specs/2026-08-31-wifi-sim-design.md` (read it first — this plan implements it).

## Global Constraints

- All engine code under `src/engine/` + `src/model/` is pure TS: **no DOM, no three, no react imports** (must run in worker and vitest).
- Time is integer nanoseconds: `type Ns = number`. Never floats for time.
- All randomness through the seeded `Rng` — `Math.random()` is forbidden in `src/engine/` and `src/model/`.
- Determinism: same (scenario, seed) ⇒ byte-identical timeline. Event queue ties broken by insertion seq.
- 802.11-2024 constants (verified against the standard corpus — do not change):
  aSlotTime = 9 µs, aSIFSTime = 16 µs, DIFS = 34 µs, aRxPHYStartDelay = 20 µs,
  AckTimeout = CtsTimeout = SIFS+Slot+RxStartDelay = 45 µs, aCWmin = 15, aCWmax = 1023,
  dot11ShortRetryLimit = 7, dot11LongRetryLimit = 4, EIFS = SIFS+DIFS+ACKTxTime(6 Mbps) = 94 µs,
  CCA preamble detect −82 dBm / energy detect −62 dBm, noise floor −95 dBm,
  OFDM rates (Mbps/N_DBPS/sensitivity dBm): 6/24/−82, 9/36/−81, 12/48/−79, 18/72/−77, 24/96/−74, 36/144/−70, 48/192/−66, 54/216/−65; mandatory rates 6, 12, 24.
  TXTIME = 16 + 4 + 4·⌈(16+8·LENGTH+6)/N_DBPS⌉ µs (Eq. 17-29/17-11).
  Frame octets: ACK 14, RTS 20, CTS 14, data = 24 (MAC hdr) + 4 (FCS) + payload.
- Vite `base: './'` (GitHub Pages). `npm test` = vitest run; `npm run build` = tsc && vite build. Both must pass at the end of every task.
- Commit after every task with a conventional-commit message.

- [ ] **Step 2: Run** — FAIL.
- [ ] **Step 3: Implement** splitmix32:

```ts
export class Rng {
  private s: number
  constructor(seed: number) { this.s = seed >>> 0 }
  next(): number {
    this.s = (this.s + 0x9e3779b9) >>> 0
    let z = this.s
    z ^= z >>> 16; z = Math.imul(z, 0x21f0aaad)
    z ^= z >>> 15; z = Math.imul(z, 0x735a2d97)
    z ^= z >>> 15
    return (z >>> 0) / 4294967296
  }
  int(maxInclusive: number): number { return Math.floor(this.next() * (maxInclusive + 1)) }
  fork(streamId: number): Rng {
    const r = new Rng((this.s ^ Math.imul(streamId + 1, 0x85ebca6b)) >>> 0)
    r.next(); return r
  }
}
```

- [ ] **Step 4: Run** — PASS.

### Task 8: Channel — CCA, reception, SINR capture

**Files:**
- Create: `src/engine/channel.ts`
- Test: `tests/engine/channel.test.ts`

**Interfaces:**
- Consumes: `EventQueue`, link table, phy constants, `EmitFn`.
- Produces:

```ts
export interface PhyListener {
  onCcaBusy(t: Ns): void
  onCcaIdle(t: Ns): void
  onRxOk(t: Ns, frame: FrameDesc, from: string): void
  onRxCorrupt(t: Ns): void          // energy ended, frame not decodable → MAC uses EIFS
}
export class Channel {
  constructor(q: EventQueue, now: () => Ns, linkTable: Map<string, Map<string, number>>, emit: EmitFn)
  register(nodeId: string, listener: PhyListener): void
  startTx(nodeId: string, frame: FrameDesc): void     // duration = frame.txTimeNs
  isCcaBusy(nodeId: string): boolean
  isTransmitting(nodeId: string): boolean
}
```

**Semantics (implement exactly):**
- Track active transmissions `{txId, frame, endNs}`. On `startTx`: schedule end event at `now+txTimeNs`; for every other registered node compute rx dBm from link table and update that node's CCA aggregate; emit `TX_START`.
- Per-node CCA busy ⇔ node transmitting, OR Σ(linear mW of all active foreign signals) ≥ −62 dBm, OR any single decodable signal ≥ −82 dBm. Emit `CCA_BUSY`/`CCA_IDLE` + listener callbacks only on transitions (compute cause: 'preamble' if any single ≥ −82 else 'energy').
- Reception: when a TX starts, each other node not currently transmitting and not already locked evaluates: rx ≥ −82 → lock onto it (emit `RX_START`). Track `maxInterferenceMw` per lock = max over the lock's lifetime of Σ(other signals)+noise. At TX end: if receiver transmitted during overlap → `RX_FAIL/txDuringRx`; else SINR = rxDbm − 10·log10(maxInterferenceMw); decode ⇔ SINR ≥ `sinrThreshDb(frame.mbps)` → `RX_OK` + `onRxOk`, else `RX_FAIL` (reason 'collision' if another TX overlapped, else 'lowSinr') + `onRxCorrupt`. If ≥2 TX overlapped and ≥1 rx failed, emit one `COLLISION` with the tx node ids.
- A node hearing energy < −82 that never locks gets CCA transitions only; if the busy period contained an undecoded ≥−82 lock that failed, `onRxCorrupt` fires at energy end (drives EIFS).
- Emit `TX_END` at end.

- [ ] **Step 1: Failing tests** using 3 registered stub listeners and a hand-built link table (no propagation module — direct dBm values):
  - Single TX: receiver at −60 dBm locks, `RX_OK` at exactly `txTimeNs`; third node at −70 gets CCA busy/idle transitions with correct timestamps.
  - Two overlapping TX at similar power at receiver (−60/−61): first lock fails with `collision`, `COLLISION` emitted, `onRxCorrupt` fired.
  - Capture: intended −50 dBm vs interferer −80 dBm (SINR 30 ≥ thresh) → `RX_OK` despite overlap.
  - Weak signal −85 dBm alone with a second −70 signal pushing sum ≥ ED... simpler: single −63+−63 signals sum ≈ −60 → CCA busy by energy, no lock, `onRxCorrupt` NOT fired (nothing ≥ −82).
  - Half-duplex: node that starts TX during its own lock → `RX_FAIL/txDuringRx`.

- **Access start** (on enqueue when idle, or on becoming idle with nonempty queue, or after TX completes): if medium idle → start IFS wait: schedule `IFS_END` at `lastBusyEndNs + DIFS` (or EIFS per Task 11) or `now + DIFS` if never busy; emit `IFS_START`. If medium busy → wait for `onCcaIdle`.
- On `IFS_END`: if `backoff === null`: if this attempt already deferred (medium was busy when the frame reached head-of-queue) draw `backoff = rng.int(cw)` (emit `BACKOFF_DRAW`) else transmit immediately (§10.3.4.2 basic access). If `backoff === 0` → transmit. Else schedule slot ticks: every `SLOT_NS` idle → `backoff--` (emit `BACKOFF_DEC`); at 0 → transmit.
- `onCcaBusy` during backoff: cancel slot tick, emit `BACKOFF_FREEZE`. On next `onCcaIdle`: re-arm IFS; after IFS emit `BACKOFF_RESUME` and continue ticking (no re-draw — §10.3.3).
- **Transmit data**: build `FrameDesc` (`bytes = dataPsduBytes(msdu.bytes)`, `mbps = cfg.rateForPeer(dst)`, `durationFieldNs = SIFS_NS + txTimeNs(ACK_BYTES, ctrlRespRateFor(mbps))`, seqNo, retryFlag = src>0||lrc>0). `ch.startTx`. - **On rx ACK while waitAck**: cancel timeout; success → emit nothing extra (RX_OK covers it); `cw = CW_MIN` (emit `CW_CHANGE`), reset per-MPDU src/lrc, ssrc=0 (short) or slrc=0 (long) per §10.3.3; dequeue (emit `DEQUEUE`), post-TX backoff: draw new backoff and run access again if queue nonempty; if queue empty still perform post-backoff countdown (§10.3.4.3) — keep `backoff` counting so a later enqueue may find it at 0.
- **ACK timeout**: emit `ACK_TIMEOUT`; failed attempt: increment src/ssrc (short frames, PSDU ≤ rtsThreshold) or lrc/slrc (long); emit `RETRY`; `cw = min(2·cw+1, CW_MAX)` (emit `CW_CHANGE`); if src > SHORT_RETRY_LIMIT (or lrc > LONG_RETRY_LIMIT) → emit `DROP`, dequeue, reset cw to CW_MIN (SSRC-limit rule §10.3.3); redraw backoff, re-access.
