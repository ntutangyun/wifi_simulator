# UWB Slice 7 — P802.15.4ab Narrowband-Assisted Multi-Millisecond Ranging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fourth UWB session mode, `mode: 'mms'`, in which a tag and each anchor range pairwise with a narrowband
O-QPSK control exchange and multi-millisecond UWB fragment trains, with Wi-Fi 6E coupling for the narrowband side
and its listen-before-talk rule; plus two lessons in a third UWB tier and the UWB records-hash determinism guard.

**Architecture:** Two pure model modules (`src/uwb/mms.ts` for fragments, trains, energy and the mandatory sets;
`src/uwb/nb.ts` for the narrowband PHY, channels, messages and LBT threshold), a per-frame PHY dispatch in the UWB
channel (sensitivity, SIR, transmit power, emission band and loss law by frame kind), `Emission.lossDb` in the
Spectrum, a pairwise round layout in `session.ts` / `network.ts`, and an MMS branch in `device.ts` (control phase,
trains, report, corrected single-sided range, block fix). View, log, inspector, frame decoder, editor and docs follow
the seams the earlier slices cut.

**Tech Stack:** existing (TypeScript, Vitest, React, zod).

**Spec:** `docs/superpowers/specs/2026-09-21-uwb-4ab-design.md` (read it: every constant's tag and every number the
lessons quote are there).
