# 衰落与多径实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 Wi-Fi 链路加上时变的阴影衰落与小尺度衰落,默认关闭,按场景开启。

**Architecture:** 纯函数的确定性哈希抽样(与调用顺序无关)叠加在既有静态链路表之上;
`channel.ts` 的 `linkDbm` 是唯一插入点;场景 schema 加一段可缺省的配置。

**Tech Stack:** TypeScript、Zod schema、Vitest。

**Spec:** `docs/superpowers/specs/2026-09-27-fading-design.md`

## Global Constraints

- **既有场景逐字节不变。** `fading` 缺省时 `linkDbm` 必须返回**同一个浮点数**,
  做法是缺省时根本不进衰落分支。`tests/fixtures/lesson-hashes.json` 与
  `tests/fixtures/uwb-record-hashes.json` 必须零 diff,且**绝不运行 `UPDATE_HASHES=1`**。
- **抽样必须与调用顺序无关。** 不用有状态的随机流;用 `(种子, 发端, 收端, 键)`
  的确定性哈希。同一帧的同一条链路查多少次都得同一个值。
- 每个常量带出处标记:`model`、`standard §x` 或 `regulation`。
- **改接口就扫接口的调用方**,不是扫任务自己的文件清单。
- **跑完整轮、读它的输出,一个功能才算建模完成。** 算术测试替代不了。

- Produces: `FadingCfg` 类型;`shadowDb(cfg, seed, tx, rx, tNs)`;

  常量 `FADING_DEFAULTS`。

- [ ] **Step 1: 先写失败的测试**

核心是三件事:纯、与顺序无关、分布形状对。

```ts
it('is pure: the same inputs give the same value, a hundred times over', () => {
  const v = shadowDb(cfg, 7, 'ap', 'sta-1', 1_000_000)
  for (let i = 0; i < 100; i++) expect(shadowDb(cfg, 7, 'ap', 'sta-1', 1_000_000)).toBe(v)
})

it('holds the shadow steady inside one coherence interval and changes across', () => {
  const a = shadowDb(cfg, 7, 'ap', 'sta-1', 0)
  expect(shadowDb(cfg, 7, 'ap', 'sta-1', cfg.coherenceMs * 1e6 - 1)).toBe(a)
  expect(shadowDb(cfg, 7, 'ap', 'sta-1', cfg.coherenceMs * 1e6 + 1)).not.toBe(a)
})

it('gives different links different fades', () => {
  expect(shadowDb(cfg, 7, 'ap', 'sta-1', 0)).not.toBe(shadowDb(cfg, 7, 'ap', 'sta-2', 0))
})

it('gives different seeds different fades', () => {
  expect(shadowDb(cfg, 7, 'ap', 'sta-1', 0)).not.toBe(shadowDb(cfg, 8, 'ap', 'sta-1', 0))
})

it('is off when it is off', () => {
  expect(fadingDb(OFF, 7, 'ap', 'sta-1', 0, 'f1')).toBe(0)
})

it('has roughly the standard deviation it was asked for', () => {
  // 20000 draws across links and intervals; sigma within 10% and mean near zero
})

it('rayleigh is mostly a small loss with an occasional deep one', () => {
  // median near -1.6 dB, and at least one draw below -10 dB in 20000
})

it('rician with a high K factor barely moves', () => {
  // spread at K = 20 dB is much narrower than at K = 0 dB
})
```

分布那三条用大量抽样统计,不要钉单个值——钉的是**形状**,不是某次抽样。

哈希用仓库已有的字符串哈希(`grep -rn "hashStr" src/`)或 splitmix32
