# UWB 感知实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给引擎加上散射体与回波,让 802.15.4ab 的感知有东西可教;默认关闭。

**Architecture:** 回波几何放在共享层 `src/engine/scatter.ts`(纯函数、与电台无关,
路径损耗作为参数传入);本切片只接 UWB 侧;回波对测距完全隐形。

**Spec:** `docs/superpowers/specs/2026-09-29-sensing-design.md`

## Global Constraints

- **既有场景逐字节不变。** `tests/fixtures/lesson-hashes.json` 与
  `uwb-record-hashes.json` 零 diff,**绝不运行 `UPDATE_HASHES=1`**(最后一个任务
  生成新课的 fixture 行时除外,且那时**只允许新增**)。
- **回波对测距完全隐形。** 时间戳、`acquired`、片段累加一个都不看回波。
  打开散射体之后 `UWB_RANGE` 必须与关闭时**逐字段相同**——这要单独测。
- **不要发明雷达截面。** 反射损耗是一个概括常数,标 `model`,注释与课程都要写明
  它不是从雷达方程推出来的。不要在任何地方写一个具体的 σ 数值然后假装它被用上了。
