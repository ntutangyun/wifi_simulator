2. **The vocabulary sheet gets the actor names in both languages and is linted, not briefed**: access point / 接入点 (never router / 路由器 / bare AP in ZH prose unless the node label says so), station / 站点, tag, ACK ("answer"), Mb/s, bytes, 仿真器 (not 模拟器), "the rate ladder" / "rung". 3. **A priced option is an instruction**: whenever a table prices "change X", the lesson states the exact editor knob and value (generation, feature flag, traffic setting) that the test applies — or the option is a variant. AMP's protected / unprotected rounds and window sizes are all such options.
4. **A formula's inputs are on the main path**: width's `16 + 6`, mumimo's 160 MHz × 2 streams, rate's 20 MHz — if the learner is invited to "do the arithmetic", every input is in the same section. AMP's airtime formula (legacy preamble + OOK symbols + padding) must list its constants once, in the lesson that introduces it, and later lessons quote them.
5. **Do not restate `why` as picture paragraph 1** (mlo); the picture starts on the mechanism.
6. **The batch reviewer greps before reading**: `router|access point`, `Mbps`, `octet`, `终端|站点`, `模拟器|仿真器`, `ladder`, and the constants sheet's numbers, across the whole track's dumps — ten minutes that would have turned Important 2 and 4 into batch-time fixes.

8. **Split-first-half keeps the hand-off sentence** (rate's "…is the next lesson"): it is what made the rate / rate-fallback boundary feel chosen rather than cut. AMP's three planned splits should each end on one.
